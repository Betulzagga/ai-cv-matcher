# AI CV Matcher 🤖📄

AI CV Matcher is a Python project that compares a CV (resume) with a job description and calculates a similarity score using basic NLP techniques.

---

## 🚀 What It Does

- Takes a CV text (resume)
- Takes a job description
- Compares both texts
- Returns a similarity score

---

## 🛠️ Tech Stack

- Python
- NLP (Natural Language Processing)
- Scikit-learn (optional)
- Git & GitHub
